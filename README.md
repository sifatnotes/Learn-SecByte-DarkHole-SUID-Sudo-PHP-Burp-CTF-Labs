## Learning Path

A practical progression through this collection is:

1. **Start with DarkHole enumeration** — identify exposed services, applications, files, and useful information.
2. **Study web access controls** — investigate how application access restrictions work.
3. **Explore sensitive-file discovery** — understand how exposed information can support further investigation.
4. **Practice upload security** — examine how unsafe file-upload handling can introduce risks.
5. **Learn HTTP request analysis** — use Burp-style request inspection to understand application behavior.
6. **Study Linux privilege escalation** — enumerate sudo permissions and other execution paths.
7. **Investigate SUID permissions** — identify privileged executables and understand their security implications.
8. **Review PATH security** — understand how command resolution can become a privilege-escalation concern.
9. **Connect the attack chain** — combine enumeration, web findings, and Linux security observations to complete the authorized CTF objectives.

## How to Use the Labs

1. Select a challenge from the direct-link index.
2. Review its objective and authorized scope.
3. Begin with reconnaissance and enumeration.
4. Record services, directories, files, permissions, and application behavior.
5. Analyze HTTP requests and responses when working with web applications.
6. Inspect sudo and SUID configurations when the challenge reaches the Linux stage.
7. Test security weaknesses only against the provided lab environment.
8. Document the discovery path and understand the underlying vulnerability.
9. Review appropriate defensive controls after completing the challenge.
